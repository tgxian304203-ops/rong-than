# 05. KHỐI LƯU Ý

## QUÁ TRÌNH LÀM VIỆC

- Từ SPCK → GitHub → Render.
- Không phải tạo app.
- Không phải tạo ứng dụng.

## QUY TẮC LÀM VIỆC

- Gửi code chuẩn 100% đúng với dự án.
- Gửi code thật 100%.
- Không được phép giả lập trong cả dự án.
- Khi gửi code phải đọc lại khối dự án và kiểm tra lỗi.
- Chỉ gửi code khi đã chắc chắn 100% không còn lỗi và khớp với dự án.
- Khi gửi code phải nói rõ dán vào đâu.
- Không hỏi những câu ngớ ngẩn.
- Phải đảm bảo đúng luồng logic.
